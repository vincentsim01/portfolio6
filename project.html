Software Development Project
Unik Loh!

Developed Unik Loh!, a full-stack software engineering project focused on a cosplay e-commerce platform with an integrated photoshoot service. Implemented authentication features including sign-up, login, and logout, along with light and dark mode functionality. Built the frontend using Next.js and connected it to the backend via custom APIs developed with NestJS. Deployed the application using Netlify, Railway, and Supabase.

Revofun

Revofun is a javascript based browser game that allows players to engage in fun and interactive gameplay.

Cafelicious

Cafelicious is a dynamic cafe directory application developed using the MERN stack (MongoDB, Express, React, and Node.js). This application allows users to effortlessly search for cafes based on three key criteria: location, cuisine type, and price range.

WeRent

WeRent is a one stop cloting rental solution developed using the React framework (Next JS, Nest JS, Prisma ORM, Supabase). This application allows users to effortlessly search for available dress and able to make sound decision using trusted reviews.
